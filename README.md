# RouteForge

A Java Swing application for generating random indoor climbing routes based on user-defined height, wall incline and difficulty.

## Demo

Demo video showcasing the main features and user interface: https://youtu.be/DtcX9jZLOc4 

## Features

* Random climbing route generation
* Slab, vertical and overhang options
* Difficulty selection from 1–10
* Library of ~180 climbing holds, including volumes
* Route image and volume information export
* Random climbing route name generator
* Favourite route names
* User registration and login
* Email sharing

## Technologies

**Java · Java Swing · File I/O · Java Collections · JavaMail**

## What I Learned

This was an early project where I learned how to build a complete application for a client rather than individual programming exercises. I gained experience with object-oriented programming, GUI development, event-driven programming, file handling, image processing, randomisation and input validation.

## Looking Back

Since developing RouteForge, my understanding of software engineering has developed considerably. Looking back, I would now:

* reduce repeated code and improve class organisation
* separate the GUI, application logic and data more clearly
* use a more structured approach to storing climbing-hold data
* improve error handling and validation
* use proper password hashing and authentication for a real application

I have also removed machine-specific file paths and hardcoded email credentials from this version so that the project is safer and easier to share.
